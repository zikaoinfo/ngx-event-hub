⚡ NgxEventHub

A lightweight Angular service for event-driven communication between components. Explore the examples below to see how easy it is to create and manage custom events.

Basic Event Communication

Send messages between components using simple event broadcasting. One component sends an event, and any component listening will receive it instantly.

Multiple Receivers

Events can be broadcast to multiple listeners simultaneously. Each receiver processes the same event independently, allowing for flexible component communication.

📡 Broadcast Pattern

The same event reaches all registered listeners at once, enabling one-to-many communication patterns.

Send a message using the "Basic Event Communication" section above to see both receivers update simultaneously.

Real-time Counter

Events can carry data of any type. This example shows numeric events being used to update a counter in real-time.

💡 Use Cases
  • Live Statistics: Update counters, scores, or metrics across the app
  • Progress Tracking: Synchronize progress bars and indicators
  • Real-time Updates: Keep dashboards synchronized with latest data

Activity Tracker

Track and log all events in your application. Perfect for debugging, analytics, or creating an event history viewer.
